## What it does

Writes a single word — the funniest and most accurate description of
your Wi-Fi — to `entry.txt`. The word is validated first (one word,
1–20 characters, not only whitespace), then read back and checked to
hold exactly what was written.

> Buffering

## Run it

```sh
python3 main.py
```

Set `ENTRY_OUTPUT` to write somewhere else:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```

- `main.py` — the entry program: validates the word, writes it, verifies it
